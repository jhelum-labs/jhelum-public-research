Abstract

Large language models built on full self-attention share six standing limitations: compute that grows quadratically with context length, hard context limits, degraded use of long contexts, weak tracking of changing state, dependence on added positional signals for word order, and heavy data and compute demands. We present Vitasta, a language-model architecture designed to change how models handle all six. Its backbone is a gated delta-rule recurrent layer that keeps a fixed-size associative state, updates it token by token, and gets word order from the recurrence itself. A few recall layers, which combine a local attention window with retrieval from a bounded chunk memory, give exact access to distant text.

We contribute a stability result for the write range, an order-sensitivity identity for the state, a multi-timescale forgetting scheme, and a cost analysis that gives the best chunk size in closed form. Testing an early version of the write-strength gate found no benefit over a simpler input-dependent rule. Testing the semantic chunk router found it reliable for topically coherent text but unable to find an isolated, thematically unrelated fact; we add a second, exact-match retrieval channel to close this gap. This is a design and analysis report. Overall progress: 25.3% on a defined validation ladder.

1. Introduction

Transformers built on full self-attention underlie nearly all current large language models. Their success comes with six recurring limitations, which are the design targets of this work:

  1. Quadratic cost. Self-attention compares every token with every other, so compute grows with the square of the context length n.
  2. Context limits. Models are trained at a fixed maximum length and degrade beyond it, and the key-value cache grows linearly with n.
  3. Context rot. Even inside the window, the use of information degrades as the context grows and depends on where the information sits.
  4. Poor dynamic state tracking. Tasks whose answer depends on an evolving state — counters, variables, permutations — are hard for fixed-depth attention.
  5. No inherent word order. Attention is order-blind and needs added positional signals such as rotary embeddings, which can limit length extrapolation.
  6. Data and resource hunger. Compute-optimal training of Transformers calls for token budgets that grow with model size.

2. Model Architecture

2.1 Overview

Vitasta is a stack of G identical groups. Each group contains k flow blocks followed by one recall block. A block has two sublayers — a mixer and a gated MLP — each with a residual connection and RMSNorm. The mixer is a flow layer in flow blocks and a recall layer in recall blocks. The input is a token embedding with no positional table.

4. Validation Plan

  1. Synthetic tasks. Multi-query associative recall, state tracking (permutations and parity), and copying. The model should still work at lengths several times longer than in training.
  2. Small-scale scaling. Train three sizes (~125M, 350M and 1B parameters) and a same-compute Transformer baseline, and compare loss against FLOPs and wall-clock time.
  3. Long context. Needle-in-a-haystack and RULER at several times the training length, looking for sudden drops.
  4. Efficiency. Tokens per second and memory at 32k and 128k context, for training and inference.
  5. Ablations. Remove recall layers; compare write strength up to 1 vs up to 2; remove chunk memory; vary flow-to-recall ratio; remove multi-token prediction.

6. Limitations and Risks

  1. Exact recall from far back is the known weakness of recurrent cores. Recall layers are tested on controlled synthetic data with encouraging results but not on a real trained model yet.
  2. The head spectrum is an untested proposal and may not help; the surprise gate it was paired with has already been tested and dropped.
  3. The write range up to 2 and the chunk memory need adapted or custom kernels.
  4. The architecture addresses data and resource hunger only in part.
  5. Retrieval cost still grows with length (though sub-quadratically).
