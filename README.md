# Jhelum Labs Research

An OpenAI-research-style web portal for the **W-1.1 model program** publications.
Built with **React + Vite** and **react-router-dom**.

## Getting started

```bash
npm install         # installs deps and then runs the docx extraction (postinstall)
npm run extract     # (re)extract .docx content from the D: drive into public/research/
npm run dev         # start the dev server at http://localhost:5173
npm run build       # production build
npm run preview     # preview the production build
```

> `npm run extract` reads the `.docx` files on the **D: drive**
> (`D:/W-1.1/W-1.1-Model/W-1-1_documents/`) via the `mammoth` library and writes
> self-contained article HTML + an `index.json` into `public/research/`.
> After extraction, the app has **no runtime dependency** on the source files.

## Project structure

```
├── extract.mjs              # docx -> public/research/ conversion script
├── public/
│   ├── logo-mark.svg        # favicon (placeholder lettermark)
│   ├── logo.svg             # placeholder wordmark
│   └── research/            # generated by extract.mjs
│       ├── index.json       # article metadata (cards + routing)
│       └── {slug}.html      # full article body per document
└── src/
    ├── App.jsx              # routes + layout
    ├── context/ThemeContext.jsx   # dark/light theme
    ├── hooks/useResearch.js # data fetching (index + article html)
    ├── components/
    │   ├── Header.jsx       # sticky nav + theme toggle
    │   ├── Footer.jsx
    │   ├── Logo.jsx         # brand logo (easily swappable)
    │   └── ResearchCard.jsx
    └── pages/
        ├── ResearchHome.jsx     # hero, featured, about, all-research grid
        └── ResearchArticle.jsx  # full article page
```

## Using your real company logo

The app ships with a placeholder lettermark/wordmark. To use your real logo:

1. Save it as `public/logo.png` (or edit `LOGO_SRC` in `src/components/Logo.jsx`).
2. Set `const USE_BRAND_LOGO = true` in `src/components/Logo.jsx`.

## Customizing content

- **Manually fix a title/excerpt:** edit `extract.mjs` (title/excerpt logic) and re-run `npm run extract`.
- **Add/remove documents:** drop new `.docx` files into the `Research-papers/` or
  `production-documents/` folders on the D: drive and re-run `npm run extract`. New
  files are picked up automatically.
